# showcase: DAgger before/after videos

Renders the post assets from `eval_closed_loop.py` output (`results.jsonl` + saved frames).

- `render.py` overlay (repo-exact projection), top-down view, flow-interpolated playback, ffmpeg writer
- `scenes.py` hero split-screen, 5-checkpoint strip, 12-drive wall, aggregate stats
- `pick_clips.py` ranks clips; the wall uses a seeded random set, not the best ones
- `make_mock.py` fake data to test layouts (NOT results)

Every number on screen is computed from the eval output. Frames are 5 Hz generated by the world model at 256x128 per camera;
playback upscales and interpolates to 30 fps, and the video says so.
